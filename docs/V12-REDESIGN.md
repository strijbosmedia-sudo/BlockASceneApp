# Block4Film v1.2.0 Stage 2: Visual Redesign Beta

**V1 Foundations:** One cinematic charcoal-gray visual system. Soft corners, restrained Block4Film red (#DC303B), consistent outline icons, readable typography and accessible focus states.

**V2 Workspace / Project Overview:** Square project tiles, wide scene tiles, New Project/New Scene within grids, search, grid/list switcher, sorting, separate floor-plan library and working management menus. Thumbnails are generated by an offline renderer from the SAVED Beat 1 positions, camera cones, set objects and background, framed to the whole 1100 × 700 blocking surface. They do not depend on the current editor zoom or selection. First scene drives the automatic project thumbnail. Edit Project and Edit Scene offer Choose Image / Use Automatic buttons; uploaded JPG/PNG/WebP files are cropped and compressed to JPEG before saving. Custom images override auto images until reset.

**V3 Editor:** Streamlined top bar and consistent toolbar symbols, charcoal tool rails, refined workspace canvas chrome, layered gray Layers and Object Properties surfaces, and a compact red-accented beat timeline. All v1.1.2 docking, left/right, float, drag and resize interactions are retained.

**V4 Supporting UI:** Dark edit/export dialogs, custom deletion confirmation, consistent context menus, notifications, tooltips and Manual. Manual chapters remain independently scrollable. Confirm deletion shows item name and requires explicit action.

**V5 Validation:** Automated tests cover Beat 1 rendering, change signatures, custom image priority, project data migration and backup persistence, library controls and accessible confirmation dialogs. Existing tests for model, playback, editing, pointer panel layout, and manual continue running. CI packages a new WINDOWS-ONLY portable prerelease for hands-on review.

## Compatibility / restrictions
- Project data format remains .blockascene schema version 2.
- Local IndexedDB and Electron application ID remain unchanged.
- Uploaded preview images are saved inside project data. Data can grow with many scenes. Images are compressed.
- No macOS or Android build is published.
- The photographic thumbnails and speculative camera fields in the reference mockups are **not** implemented; cards use actual saved blocking diagrams instead.
- Dark redesign remains a beta until visually inspected on Windows, including window sizes, preview image import, docked panels, animation and exports.
- The known-working v1.0 and v1.1.x Windows releases are preserved.
